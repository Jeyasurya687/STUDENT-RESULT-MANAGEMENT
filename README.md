# 🎓 Student Result Management System

A simple and responsive **Student Result Management System** developed using **HTML5, CSS3, and JavaScript**.

This project allows users to enter a student's register number and view their academic results, including subject marks, total, average, grade, and pass/fail status.

## 📌 Features

- 🔎 Search student result using Register Number
- 👨‍🎓 Display student name and academic details
- 📝 Display subject-wise marks
- ➕ Automatically calculate total marks
- 📊 Calculate average percentage
- 🏆 Generate grade automatically
- ✅ Display Pass / Fail status
- ⚠️ Show an error for an invalid Register Number
- 📱 Responsive design for mobile and desktop
- 🎨 Clean and user-friendly interface

## 🛠️ Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling and responsive design
- **JavaScript (ES6+)** – Result search, calculations and dynamic content

## ⚙️ How It Works

1. Enter the student's **Register Number**.
2. Click the **Get Result** button.
3. JavaScript checks the entered register number.
4. The student's details and marks are displayed.
5. Total and average are calculated automatically.
6. Grade and Pass/Fail status are generated based on the marks.
